Navigable Windows Explorer previews for 15 extensions: SLDPRT, SLDASM, STEP,
STP, P21, STL, OBJ, PLY, GLB, GLTF, FBX, 3MF, IFC, IFCZIP, and DXF.

Extract the ZIP and double-click **Install.cmd**. Enable the Preview pane with
**Alt+P**. No administrator access is required. Existing default apps and the
main VTX app's Open-with commands are preserved. **Uninstall.cmd** restores
previous preview handlers.

SolidWorks saved images appear first, then a navigable GPU view loads in the
same pane. Cached images cover later selections. Middle-drag rotates,
Ctrl+middle-drag pans, scroll zooms, and F fits. With the live model focused,
S toggles a center section and X toggles the exploded view on assemblies.
DXF uses a 2D view.

This is a separate, unsigned Windows x64 preview package. Main-app automatic
updates do not update it. Parasolid X_T/X_B, IGES, F3D, and SLDDRW are not
supported by this release. See the included README and third-party licenses.
